# Figuras geométricas

Ejecute `Main` desde el IDE para abrir la interfaz Swing. Seleccione un círculo
o un triángulo, introduzca sus medidas y pulse **Crear figura** para añadirlo
a la tabla. Las medidas deben ser positivas y, para un triángulo, cumplir la
desigualdad triangular. Se admite tanto el punto como la coma decimal.

Para utilizar la interfaz de consola anterior, ejecute `Main` con el argumento
`--cli`.

Las pruebas son clases ejecutables sin dependencias externas:
`Views.FabricaFigurasTest` y `Views.SistemaSwingTest`. La segunda requiere un
entorno gráfico.
